# ⚽ TP : Nettoyage et Exploration de Données (Football Players Dataset)

Ce projet porte sur le nettoyage et le prétraitement d'un jeu de données relatif aux joueurs de football, la réalisation d'une analyse exploratoire des données (EDA), ainsi que leur visualisation.

---

## 📌 Description du Projet

L'objectif principal de ce travail est de transformer un jeu de données brut contenant des anomalies, des valeurs manquantes ou incohérentes (`football_players_dirty.csv`) en un jeu de données propre et exploitable (`football_players_cleaned.csv`) à l'aide de Python et Pandas.

---

---

## 🛠️ Étapes Réalisées (Workflow)

1. **Chargement des Données** : Importation du jeu de données brut.
2. **Analyse Exploratoire (EDA)** : 
   - Identification des valeurs manquantes (*nulls*), doublons et types de données.
3. **Nettoyage des Données** :
   - Traitement des données manquantes (Imputation / Suppression).
   - Correction des formats de colonnes et des erreurs de saisie.
4. **Exportation** : Enregistrement du fichier nettoyé `football_players_cleaned.csv`.
